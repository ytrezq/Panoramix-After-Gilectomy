## Regressions

249 regressions in 156 contracts.

| kind | high | medium | low |
|---|---|---|---|
| coverage | 0 | 0 | 1 |
| loop | 0 | 18 | 5 |
| naming | 0 | 3 | 7 |
| simplification | 0 | 71 | 144 |

No regression changes what the code does, and none is high. They are losses of readability, and most share a few causes, which the reviewers name:

1. **The free-memory pointer after loops and joins.** The new handling keeps only a constant floor across a loop or a join.
   - Two reads of `mem[64]` with no write between are then no longer equal, and `_x - mem[64]` doesn't fold.
   - Stores made through the pointer are not carried into the reads after them.
   - As a result, calls, string and custom-error reverts, event data, returns and mapping keys that round 1 showed decoded print as raw memory again. This is clearest after Governor's `hashProposal` encoding loop (`execute`, `queue`, `cancel`) and in the `permit(bytes)` paths.
   - Some storage-to-memory copies are `while` loops again.
   - A call's function sometimes prints as a memory slice (`call timelock.mem[... len 4]`).
2. **The pointer's value written in full.** The variable that named a buffer's base is replaced by the whole sum it equals (`mem[32 * _18 + ceil32(_1) + ceil32(_5) + 192]`), so some texts' lines are several times longer.
3. **Loops.**
   - A check that reverts is again a loop's header, with the real bound an exit inside the body (`claimComp`).
   - Some inlined loops became `while True`, with the rest of the function inside their exit branch.
   - A hash loop's variable is carried as an offset from its first value (`s = sha3(s + h0) - h0`).
4. **Shared reverts.** The guards' reverts merge into one revert at the end of the function, so the main path nests under the inverted conditions.
5. **Split arguments.** A no-op re-store before a selector's store splits an address or `bytes16` argument into `Bytes(28, x >> 32), Bytes(4, ...)`. The phantom field it makes can turn a mapping of addresses into a struct.
6. **SafeMath's exactness.** The exact revert data print as the raw Error payload with the padding memory holds; this is the price of the c00034 fix.

The execution checks found no regression:

- **npm corpus (861 contracts):**
  - stagecheck: 78,122 calls, 0 different, 0 bugs at every stage;
  - text_check: 0 different and 0 lines unparsed in both worlds.
- **These 400 contracts:**
  - stagecheck: 123,664 calls, 0 different, 0 bugs;
  - text_check at seeds 0 and 6: 0 different, 0 lines unparsed.
- **The same 400 at 16 calls per selector** (4 by default) find 4 contracts whose text differs from the bytecode on one call or two. The round-1 texts differ the same way, so these are older errors, not regressions:
  - c00158 and c00160 (Aave, `getReserveNormalizedIncome`): a checked subtraction sits in the right operand of an `and`, so the text returns where the bytecode reverts with Panic(17).
  - c00144 and c00157 (Governor, `getActions`): the second offset of the returned ABI data differs in a random world.
