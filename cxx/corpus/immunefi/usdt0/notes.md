# USDT0 (usdt0): EVM, sources not public

- Scope (47 assets): the USDT0 token (OUpgradeable / TetherTokenOFTExtension; HyperliquidExtension on HyperEVM) and its OApp (LayerZero OFT) on about 20 EVM chains (Arbitrum, Optimism, Polygon, Mantle, Berachain, Ink, Unichain, Sei, Flare, Monad, Plasma, Corn, Rootstock, X Layer, Stable, Conflux eSpace, MegaETH, Morph, HyperEVM, Hedera, Tempo), and the OAdapterUpgradeable OApp adapters on Ethereum (one of them for IOTA).
- Non-EVM parts: the Stellar SAC manager and OApp (Soroban), and the IOTA objects (Move).
- No public repository holds these contracts: the developer, Everdawn Labs, publishes only usdt0-audit-reports on GitHub (its devtools repository is a fork of LayerZero's developer utilities, not the USDT0 code), and searches for the contract names and the audits (OpenZeppelin, ChainSecurity) found no source repository.
- Nothing copied; the sources exist only as verified code on the explorers.
